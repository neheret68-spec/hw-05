# hw-05  Лабораторна робота 5

Проєкт виконано для лабораторної роботи 5: адаптивна верстка сайту, медіа-запити, мобільне меню, переходи та анімації.

Використано попередній проєкт з ЛР1–ЛР4. Додано адаптацію головної сторінки та сторінки таблиці для екранів від 320px, метатег viewport, медіа-запити для трьох точок перелому: 1158px - десктоп/планшет, 768px - планшет/мобільний, 480px - малий мобільний екран. Додано мобільне меню, підключене окремим файлом `mobile-menu.js`, плавні переходи для hover/focus-станів, анімацію заголовків і зображень, а також `srcset` для растрових зображень x1/x2 та медіа-запити для фонових зображень під retina-екрани.
